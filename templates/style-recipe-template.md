# 风格蒸馏词条模板

[返回词条模板](entry-template.md) · [短标签对照](../notes/style-tags.md)

用于整理者已经命名的创作者短标签。正式词条仍按[词条模板](entry-template.md)的栏目书写；本页只补充蒸馏时容易写混的几项。

## 写入前

- 短标签先登记到[风格短标签对照](../notes/style-tags.md)，再写词条。对照表是唯一目录。
- 只使用已经拿到的主页或原帖链接。没有状态链接时，原帖一栏写待补充，不编造地址。
- 授权未知则写「未确认」。主页链接不写成许可。
- 未出图则状态写「未测试」，效果图一节写「待生成」。不放占位图、他人截图或虚构结果。
- 逐字原文与蒸馏分开。蒸馏标明「风格蒸馏材料」，并写明未与原帖逐字核对。

## 建议栏目

| 字段 | 怎么写 |
| --- | --- |
| 主分类 | 从[分类规则](../categories/README.md)选一个 |
| 整理者短标签 | 与对照表用字一致 |
| 提示词作者 | 显示名与账号；未核验就写明 |
| 授权状态 | 未确认 / 作者许可 / 明确许可条款 |
| 状态 | 未测试 / 已测试 / 待改进 |
| 示例图归属 | 无图时写「无」 |

正文顺序与词条模板相同：基本信息、效果图、原始提示词、我的理解、实际提交版本、实验记录、可复用模板、使用边界。

原始提示词放已有的全文或蒸馏示例。可复用模板放带变量的母版，并写明变量还没有提交测试。个人理解不归到原作者名下。

## 蒸馏示例的标注

```text
以下为本项目根据公开帖方向整理的风格蒸馏，不是逐字摘录。
作者：〔显示名（@handle）〕
主页：〔已有链接，或写待补充〕
授权：未确认
```

一句口味、堆叠顺序或字段表，写在「我的理解」。一次蒸馏只固定一种版式，另一种版式另起一节，避免把两种帖文合成一段无法核对的文字。
