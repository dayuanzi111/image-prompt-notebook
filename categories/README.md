## 交叉题材如何归类

- 插画风格海报：主分类为海报与平面设计，“装饰插画”为标签。
- 武侠人物浮世绘：主分类为插画与人物绘画；“人物”不等于人物摄影。
- 教材圆珠笔涂鸦：即使以纸面照片呈现，创作主体是插画改绘，仍归插画与人物绘画。
- 砖缝小草的城市随拍：归风景与城市日常，即使是近景也不归人物或产品摄影。
- 人物位于风景中：按主要视觉目标判断，突出面孔与互动归人物摄影，突出环境归风景。
- 服装 Lookbook：若主要目标是成衣与配饰设计，归产品与商业视觉；模特是展示手段。
- 以穿搭呈现居家生活与抓拍状态：归人物摄影；如词条014的男友衬衫四连拍，服装用于建立人物情境。

每条只占一个主分类，标签可以共享。现阶段保留统一词条目录，通过分类索引检索，不移动已有文件，以保持旧链接可用。编号不因分类改变而变化。分类增长到影响检索时，再考虑新增主分类。
