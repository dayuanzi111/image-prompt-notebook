# 模型与提示词：美学方向与细节约束

[返回学习笔记](README.md) · [词条 003](../entries/003-galaxy-saving-gaze/README.md)

整理日期：2026-10-12。以下区分整理者的经验、可查证资料与待验证建议；不将补充观点归为提示词作者 lyshen 的主张。

## 整理者提出的经验

Seedream 可先强调美学方向；GPT Image 2.5 可把构图、人物关系与细节说明得更明确，根据自己的需求补充。这一思路保留为**待验证的模型适配经验**，不是两种模型的硬性使用规则。

整理者同时提出“Seedream 与 GPT Image 2.5 底层完全不同，GPT Image 2.5 走自回归路线”。本次核查未取得足够的一手证据确认完整比较，因此不作为已确认事实发布。

## 资料能确认到哪里

- 字节跳动官方明确说明 **Seedream 4.0** 采用 Diffusion Transformer（DiT）与 VAE，并具备美学、指令遵循和多模态理解能力。这一结论有版本范围，不能直接概括所有 Seedream 版本。[Seedream 4.0 官方发布说明](https://seed.bytedance.com/en/blog/seedream-4-0-officially-released-beyond-drawing-into-imagination)
- OpenAI 的 GPT Image 2.5 提示指南强调主体、构图、风格与约束，以及逐项迭代；短提示词、描述段落和结构化格式均可使用。已查看的提示指南与生成指南未明确说明 2.5 的自回归架构，故本笔记不确认该架构说法。[GPT Image 2.5 提示指南](https://developers.openai.com/api/docs/guides/image-prompting)、[图像生成指南](https://developers.openai.com/api/docs/guides/image-generation)

即使架构差异成立，也不能直接推出“某模型只需要美学词”或“另一模型提示词越长越好”。提示词策略需要在具体模型版本与任务上测试。

## 本项目的补充建议

1. **先确定情感中心。** 在“拯救银河系的眼神”中，眼神与自然笑容是首要目标。
2. **把美学写成可见条件。** 低饱和、低反差、柔亮面颊、保留阴影与背景柔化，比只写“氛围感”更易判断是否达成。
3. **详细说明容易歧义的关系。** 谁在前、谁被遮挡、眼睛看谁、哪些区域清楚，是双人构图的关键。
4. **按需求增加细节。** 不要求复刻耳饰时，可省略耳饰规格；需要精确构图时，补充位置和遮挡。每个细节都应服务目标。
5. **避免相互冲突。** “偏暗曝光”不等于压黑肤色，“低反差”不等于灰雾，“浅景深”不等于所有脸部都模糊。可以用明确的保留条件处理这些边界。

这些建议是本项目的提示词设计判断，尚未完成跨模型验证。

## 如何测试这条经验

先用同一提示词、比例与参考条件比较模型，再分别优化提示词。记录 Seedream 的具体版本，以及 GPT Image 2.5 的具体型号，不笼统只写模型家族。

| 测试组 | 描述变化 | 观察重点 |
| --- | --- | --- |
| 基准 | 同一收录文本 | 起点差异 |
| 美学优先 | 保留必要构图，压缩配饰细节 | 光色、气氛与自然度 |
| 关系与约束优先 | 明确位置、遮挡、焦点和优先级 | 构图、眼神与景深遵循 |

每组重复生成，区分偶然好图与稳定表现。不同平台若有自动改写提示词或隐藏设置，应一并记录。目前词条 003 只有一次内置工具生成，底层模型未确认，**不能作为 Seedream 与 GPT Image 2.5 的对照证据**。
