## 我的理解

- 构图：一张脸的特写。焦点写在一只眼睛上，虹膜是锐利的蓝色。湿发垂在脸上。
- 色彩与光：温暖的橙色和金色高光，明暗对比强烈。水珠要在高光下看得见。
- 材质：湿润的皮肤、胡须的纹理、发丝上的水。原文用了「粗犷」「超细节」「照片级真实」「电影风格」「超写实 8K」。
