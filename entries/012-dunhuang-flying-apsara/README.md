## 构图与风格拆解

- 人物横卧与长裙顺应横幅；头部位于左侧，裙摆向右延伸。
- 飘带通过弧线与S形跨越画面，可用于建立动势，也容易覆盖手、笛子或背景。
- 石青、石绿作为主体环境色，朱红织物和金饰构成对比。
- 真人面容负责表情与立体感，衣饰、云纹和色块承担绘画语言；需控制两者的融合程度。

## 实际体验与不足

| 观察项 | 一次输出的表现 |
| --- | --- |
| 人物与舞姿 | 横卧、吹笛意图清楚；裙摆遮挡较多，身体连接和腿部姿态未充分验证 |
| 面容融合 | 面部较写实，背景较平面；这种对比有层次，也可能像真人拼贴到壁画上 |
| 飘带 | 盘旋动势明显，但数量、纹样和交叠较多，部分空间关系不清楚 |
| 背景 | 额外出现许多小人物、洞窟式画面和光环，超出实际提交的“单一人物”约束，视觉密度偏高 |
| 纸面与墙面质感 | 色块有较明显斑驳，整体偏旧壁画；与“现代重绘、克制微纹理”的目标存在差距 |
| 颜色 | 蓝绿、朱砂与金色关系鲜明，局部金纹偏繁密 |
| 手与乐器 | 双手持笛可辨，但指位、笛孔与吹奏姿态仍需局部核对 |

这次效果适合繁复华丽的方向；若更重视空灵和现代感，建议降低背景与金纹密度，而不只是继续增加清晰度。以上是本项目观察，不归为原作者观点。

## 本项目的补充建议

1. **明确背景方向。** 可选繁复壁画叙事背景，或简化的矿物色底与祥云。若只想要一个人物，补充“背景不出现人物、佛龛或小肖像”，并检查结果。
2. **控制飘带数量和路径。** 指定2—3组主飘带，次要带子少量；注明起点、交叠与前后，不遮住脸、笛子和手。
3. **把人物融合写具体。** 例如面部保留真人比例，但边缘与阴影略绘画化，让它与工笔线条和矿物色统一。
4. **区分华丽与做旧。** 金饰与织纹能带来华丽，不必依赖满屏剥落、斑驳或破损。可分别设定纹样密度和墙面质感。
5. **按用途预留空间。** 横幅文章配图可指定一侧留出连续色面；若用于封面，标题在后期排版，并保护脸与乐器的裁切范围。

如想对应某一壁画，应提供具体参考并明确哪些元素要保留；当前图只能作为自由美学改编，不能替代历史考据。
