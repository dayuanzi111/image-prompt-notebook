## 我的理解

- 构图：2:3 竖画幅。右后方略高的俯视机位，全身中全景，无前景遮挡。人物在画面正中央，背对镜头，四分之三右后侧身，朝向大殿。腰背直立，双肩舒展。双臂屈肘，双手在胸前向上合十。双腿并拢跪在斜面拜垫上，双脚向后探出垫沿，脚趾搭在黑色平底一字带凉拖上，脚跟与足弓悬空翘起。
- 色彩：明亮暖棕、浅米灰与冷白肤色，自然高调。拜垫是浅米粉色，衬衫深咖，短裙棕色豹纹，小包和拖鞋是黑色，左脚踝有红绳，远景廊檐是朱红。
- 光线或材质：晴日，光从左后上方斜射。发丝中部有一道明亮高光，原文称为绸缎般天使环。中长焦浅景深，细腻瓷肌精修。材质写到顺直发丝、豹纹面料、软质皮革拜垫和赤足肌肤。小腿迎光面是通透奶油白；悬空的脚跟与足底边缘写到珊瑚粉红的次表面漫反射。浅灰石板地面有拖鞋和人体的暗影。
- 关键约束：高清数码相机、户外晴日抓拍、写实。侧颜隐在栗色长发后面。背景是浅灰石板广场、右侧一位白衣驻足男子，以及远景雕梁画栋的古寺朱红廊檐。
