## 我的理解

笔记里的写法大致按这个顺序叠。每一层只补充下一件看得见的东西，人物保持不动：

1. 超写实或 photorealistic，加上题材，如编辑自拍、夜景抓拍、高反差肖像。
2. 头发、妆和表情。
3. 姿态与取景。
4. 服装，以及场景里的两三件道具。
5. 光线。笔记里出现过侧硬光、室内暖光、直闪、单色绯红、夜景混合光。
6. 镜头：85mm、35mm、鱼眼，或浅景深。
7. 画幅与质感：9:16 或 3:4，胶片颗粒，可见毛孔。
8. 负向：不要文字、水印、塑料皮肤、变形的手、AI 感。

常见槽位，同样来自笔记，尚未在本项目测试，也没有逐条原帖：

- G7X 直闪六格。指卡片机直闪、一次排出六格的题目，不表示本项目用该机拍摄。
- 连帽衫贴脸自拍。
- 高反差编辑肖像。
- 日本夜晚街头抓拍。雨夜便利店示例接近这一槽，地点改成了便利店门口。
- 用自拍参考图锁身份。必须另附参考图，并在实验记录里写明参考条件。没有参考图时，结果只是一次新的肖像。

按词条模板，阅读时落在这四项：

- 构图：脸占据大部分画幅，或用四分之三、低角度自拍。环境只留两三件能认出来的道具。
- 色彩：可以压成灰调，也可以拉高反差。雨夜示例是暖橱窗光加冷色轮廓。
- 光线或材质：先写光的方向、软硬和颜色，再写毛孔和轻微颗粒。颗粒用来加照片感，毛孔仍要单独保留。
- 关键约束：句末负向词挡住文字、水印、塑料皮肤、过度磨皮和多余手指。负向词负责排除，风格仍靠前面的光和镜头建立。

以上是本项目的阅读，不是原作者的解释。
