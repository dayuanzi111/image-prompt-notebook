## 原始提示词

以下按整理者提供的原文保存，仅整理段落空白。示例填写、实际提交与使用建议另列。

```text
【古诗词】{填写诗词标题、作者及原文}
【海报主标题】{提取2–4个代表性汉字}
【核心意象】{如双色江水、金黄菜花、橙绿果林、桃花游鸭}
【画面场景】{填写或由AI根据诗词提取}
【主色调】{选择2–3种协调的东方传统色}
【画幅比例】9:16

根据古诗词创作一张具有教科书级插画质感的新中式细线设色艺术海报，将诗中的景物、色彩与情绪转化为完整、富有东方美学的视觉场景。

【画风与质感】

采用现代东方装饰插画与传统工笔线描结合的绘画语言。树冠呈柔软蓬松的云团状完整色块，边缘具有细腻的粉末点染质感，内部穿插纤细、连续、自然分叉的墨黑枝条。

植物、花卉、动物与其他景物根据真实形态适度概括，使用饱满、均匀的平面设色与少量精细墨线。如有传统建筑，采用规整青绿瓦片、优雅飞檐、暖白墙面与朱红木结构。整体精致、干净、哑光，保留轻微纸本质感。

【构图与空间】

采用高位俯瞰、东方散点透视与现代平面构成。通过大面积色块、自然曲线、局部包围和暖米白留白组织画面，形成清晰的视觉重心与空间层次。

根据诗词灵活变化构图，突出最有代表性的意象与视觉关系。主体精描，辅助元素概括，地面与水面尽量简洁，只用少量细线和不规则墨色阴影表现空间，避免无关元素堆砌。

【东方配色】

采用石青、石绿、黛青、朱砂红、赭红、橙金、暖象牙白等东方传统色系。以一种主色形成视觉重量，一种对比色突出核心意象，搭配墨色线条与干净留白。

色彩饱满、连续、均匀，具有鲜明的冷暖或明度对比。保持完整的大色面，不使用杂乱渐变、厚重纹理和过度做旧效果。

【中文海报排版】

在画面下方或侧边的深色区域，融入大幅暖象牙白中文标题，采用厚重、端正、优雅的东方艺术字体。

在适当留白处加入小型纵排原诗句、准确的作者署名及少量朱红印章。文字清晰，层级分明，具有成熟的文化海报设计感。

【最终质量】

远看具有鲜明完整的大色块与优美构图，近看拥有精致细腻的工笔线条。保持建筑精描、植物概括、背景留白的视觉层级。

避免写实摄影、3D、动漫、油画厚涂、浓重水墨、密集独立叶片、复杂背景、过度颗粒与人工做旧。

最终呈现一张诗意鲜明、配色惊艳、画面精致且具有统一系列美学的新中式古诗词艺术海报。
```

“教科书级”是风格与质量诉求，不代表已通过教材审定。

## 简要使用方法

1. **填写诗词与署名。** 使用准确的标题、作者和原文；选择想表现的两三句，避免把全诗所有景物同时堆入画面。
2. **确定一个视觉中心。** 用2–4字作海报标题，提取一组核心意象；场景可以让AI提取，但要检查是否符合诗意与季节。
3. **颜色要搭配，并有主次。** 选2–3种协调主色，明确哪种占大面积、哪种突出主体；暖象牙白留白和墨线用于连接整体。红绿可用石绿为底、朱红集中在花团，避免两色等量铺满、互相争抢。
4. **控制细节与留白。** 保留一个主要场景，辅助景物概括；如果结果太繁密，优先减少远景层次和花叶数量，而不是增加更多“高清”形容词。
5. **改作插画时替换排版要求。** 删除“中文海报排版”段，改为“无标题、诗句、印章和任何文字”，再按书页版心调整比例。发布前检查文字、手足和核心意象的表现。

可尝试的配色方向（本项目建议，不是固定规则）：石绿＋朱红＋暖象牙白表现春日花岸；石青＋橙金＋暖象牙白表现秋色；黛青＋石绿＋少量朱砂表现清幽山水。应根据诗词内容选择，尚未分别生成验证。

## 整理者的评价与插画用途

整理者认为：**这是一个十分好用的提示词，也可以用作插画。** 这条评价作为使用心得保留，不意味着每首诗或每次生成都能稳定达成同一风格。

本项目补充：模板把意象、构图、配色与文字分开，方便替换诗词而维持系列方向。用于书籍正文插画时，宜去掉文字、简化背景，并让颜色呼应全书；章节扉页可保留安静区域，供后期排版。具体书籍版式尚未测试。
