## 我的理解

- 构图：镜头离脸很近，机位像副驾或贴脸。背景很快变黑，不负责讲另一件事。
- 色彩：冷蓝夜景，或冷粉压在白与黑上。色彩偏移宜轻，避免变成均匀的一层色罩。
- 光线或材质：直闪落在眉骨、鼻梁、锁骨这一类小面积。T 区高光窄。嘴唇可以有一点水光，脸颊保持干。薄底妆要留毛孔。
- 关键约束：负向词同时限制皮肤处理和人体结构。全脸油膜和塑料皮肤是这一路最需要分开看的两项失败。

日景冷白的字段式（美术馆台阶）和室内沙发的直闪一段式，可以跟车厢夜景、贴脸方图对照着看。前者是白天的冷白日光、石材反射和极弱柔闪；后者是家里的机顶直闪，人物正面略过曝，背景留冷蓝灰暗部。四则都还没有在本项目出图，不能先说哪一种更稳。

韩系妆面里容易做出的「风尘感」，有一条公开帖专门在纠。这里只记技法补丁，不转载那条帖子的原文：腮红和高光要收住，留下毛孔和不对称，直闪的衰减要硬，后期不要走商业精修。和上面的光线判断放在一起，就是「窄高光 + 干爽脸颊 + 非商业精修」。来源：[约 2026-10-26 17:34](https://x.com/FromSummerF/status/2114651939476848902)。这是本页的阅读，不是把原帖改写成另一套提示词。
