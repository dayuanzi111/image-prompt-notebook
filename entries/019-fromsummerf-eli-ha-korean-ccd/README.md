“CCD”“直闪”写的是观感。生成结果不能当成相机实拍，也不能用来证明某台 CCD 的色彩。

## 我的理解

- 构图：镜头离脸很近，机位像副驾或贴脸。背景很快变黑，不负责讲另一件事。
- 色彩：冷蓝夜景，或冷粉压在白与黑上。色彩偏移宜轻，避免变成均匀的一层色罩。
- 光线或材质：直闪落在眉骨、鼻梁、锁骨这一类小面积。T 区高光窄。嘴唇可以有一点水光，脸颊保持干。薄底妆要留毛孔。
- 关键约束：负向词同时限制皮肤处理和人体结构。全脸油膜和塑料皮肤是这一路最需要分开看的两项失败。

以上不归为原作者的解释。一段式和字段式应分开提交，才能看出版式本身有没有影响。

## 可复用模板

方括号为变量。冷蓝夜景或冷粉白黑底、贴脸或副驾，按槽位选一项，避免叠成互相打架的光。尚未测试。

```text
[画幅]，CCD 直闪[冷蓝夜景/冷粉白黑底]，韩系女友视角[贴脸大头/夜归副驾]，真实低照度数码抓拍质感，[背景色]暗部欠曝。
成年年轻女性，[妆容细节：眼线/唇/底妆/高光位置]，[发型]。穿[服装面料]。[姿态与和镜头关系]。
[机位：平视/略仰，距离]，[直闪打在哪些部位]，背景快速跌入暗部。
不要塑料皮肤、全脸油膜、过度磨皮、多余肢体、头颈断裂、文字水印。
```

母版里的「姿态与和镜头关系」按整理笔记原样保留，填写时写成一个具体姿态即可。
