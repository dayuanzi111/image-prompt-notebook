## 整理者补充：目标明确时，短提示词可能更好

整理者的经验是：**对于 GPT 图像生成，有时候目标明确的简短提示词，比事无巨细的长提示词更容易得到理想效果。** 这里的“更好”主要指符合想要的气质和审美，保留为个人经验，不写成所有版本、所有任务都适用的结论。

本项目的补充判断：关键是信息是否服务目标，而不是字数。几个辨识度高的词可以集中表达主体、质感与情绪，给构图和次要细节留出空间。扩写若擅自加入服装、地点、姿态和布光，可能把原来的开放方向收窄成另一张图；这次从抽象人像方向变成霓虹街头写真就是需要区分的变化。

涉及多人位置、精确文字、参考图保留、产品结构或指定版式时，详细说明仍有价值。建议先保留核心目标，只针对结果中真正缺失或有歧义的一项补充，而不以“越短越好”替代“越长越好”。这些是编辑建议，尚未完成长度对照测试，亦非尘林 Spark 的主张。

更完整的方法见[模型与提示词学习笔记](../../notes/model-prompting.md#目标明确时短提示词可能更有效)。
