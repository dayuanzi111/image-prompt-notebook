## 我的理解

- 构图：9:16 竖版。夏日室内窗边，真实手机随手抓拍。动作不是固定一格，原文并列了撩开额发、拿起冰凉饮料、靠近窗户透气，或用手背轻触额头。
- 色彩：原文没有指定色板。潮湿空气和皮肤的细小反光压过配色。
- 光线或材质：空气闷热。太阳穴、额头边缘和颈侧有极轻微的自然出汗。汗是不连续的小面积反射，有的地方看得见，有的地方没有。少量细发因湿度贴在皮肤上，接触处有细微阴影。保留毛孔、局部肤色变化和轻微油脂光泽。
- 关键约束：不要满脸水珠、过度湿发或商业油亮妆面。保留角色标志性的发型、发色和服装，贴附位置随头发长度变化。整张图保持潮湿空气、发丝黏附和原生手机摄影的统一质感。

以上是对原文用词的阅读，不是改写，也不是出图之后的观察。
