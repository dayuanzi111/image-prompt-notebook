## 本项目的补充见解

1. **宽松感来自结构关系。** 先保留落肩、袖口余量、衣身宽度与衣摆长度，再按需要指定布料。若把腰部收得过紧，容易失去松弛感。
2. **失败照片也需要可读性。** 每帧只突出一种瑕疵：失焦、运动模糊、倾斜或闭眼。不要让四帧都重度模糊，否则服装和人物难以识别。
3. **服装条件要逐帧成立。** 抬手、走动或坐下可能改变下摆位置。若短裤必须不可见，可限定小幅日常动作，并检查四帧中的遮挡关系。
4. **明确四连拍的交付形式。** 一张2×2拼图适合整体展示；四张独立9:16图片便于分别发布，两种版式应分别说明。
5. **区分随拍与严格连续。** 若只要生活感，可以保留几个小动作；若要模拟同一秒内的连拍，应固定机位、动作轨迹与背景，而不是四种彼此独立的姿势。
