## 整理者见解与补充

整理者建议进一步指定**动作**与**想要的图案类型**，也可以让动漫人物与诗人同框。以下是本项目补充，不归入原作者文本；尚未分别生成。

| 要控制什么 | 写法示例 | 作用 |
| --- | --- | --- |
| 人物动作 | 双手握车把、脚踩踏板、袍角向后飘 | 比“骑车”更明确，便于检查手脚与道具关系 |
| 图案类型 | 自行车道具 / 小漫画角色 / 表情符号 / 小幅漫画格 | 确定新增的是哪一种画面元素 |
| 新角色位置 | 指定动漫角色站在诗人右侧，约半个头像高 | 控制大小，避免新增角色抢占原肖像 |
| 同框互动 | 两人击掌 / 一起撑伞 / 交换书本 | 让角色产生关系，而非只把两幅图放在一起 |
| 笔触统一 | 新角色也用蓝黑圆珠笔细线和随手排线 | 避免变成彩色动漫贴纸拼贴 |
| 保留区域 | 保留原人物脸、头巾、标题和正文，只在衣袖与周围加画 | 让原印刷层与新增涂鸦层都能被看见 |

我的补充判断：趣味最好来自“严肃原形象＋一个清楚的新行为”。每次选一个主要动作和一组辅助图案即可，太多角色、文字和道具会掩盖课本涂鸦的随手感。

若让动漫角色同框，可以指定角色名、位置、大小与互动，同时要求它使用同样的业余蓝黑笔触。原诗人的印刷面貌保持可见，动漫角色属于后加涂鸦层，不把整页重新绘制成动漫画。

```text
生成一张竖幅3:4写实纸面近拍照片，内容是一页模拟中文语文教材上的圆珠笔二次涂鸦，不要伪称真实出版页，不用任何出版社标识。主题为“杜甫很忙：骑自行车”。页面中心偏左是一幅原本印刷的杜甫古代半身肖像，传统黑灰细线木刻教材插图：瘦长脸、短胡须、古代头巾、宽袖长袍，神情严肃沉思，头巾脸部与上身的灰黑原印刷线条必须可见，与后加蓝黑圆珠笔区分。学生在原插图上直接用蓝黑色圆珠笔追加涂鸦，让原人物仿佛骑着一辆简陋自行车：保留印刷头部、胸口和衣袍，在插图内与边缘追加向前伸到车把的手臂，宽袍下追加踩踏动作、自行车三角车架、两个椭圆轮子、歪歪的辐条、车链及几条速度线。新增线条必须跨过原印刷插图边界并与人物相接，像课堂闲时真实学生随手改画，不是在旁边单独画一幅成品。圆珠笔只有蓝黑细线，排线与反复描线形成深浅，保留轻微断线、粗细不均、重复描线和错误修正的痕迹，车轮有一点不圆，辐条不规整，手臂和腿略笨拙但明确。杜甫脸和头巾仍主要是印刷插图，新增自行车是较鲜明蓝黑墨水。画面不要精致职业插画，不要复杂完美雕刻排线，不要整页漫画。页上方印刷标题准确“杜甫”，画像下方印刷小字准确“诗人杜甫”，右侧少量浅灰印刷教材短文，正文可用清楚且简短的“杜甫，字子美，唐代诗人。”，不要长篇诗词。页边随手写小字准确“赶着去写诗”，与正式印刷不同。普通略暖白色教材纸，轻微纸纤维，真实灰黑印刷，自然窗边光，页面轻微倾斜，近距离拍摄能辨别圆珠笔线条。没有强做旧，没有泛黄破损，没有均匀颗粒，没有额外彩色笔、3D人物、动漫脸、水印、出版社logo。重点是保留原印刷教材人物，再用业余蓝黑圆珠笔幽默加画的真实层次。
```
