## 简要使用方法与补充建议

1. **先确定人物和一个动作。** 可替换【嫦娥】为其他人物，但应同时指定动作对象；“谁触碰谁、哪只手、触碰哪里”比堆叠寓意词更容易判断。
2. **颜色分工清楚。** 选一个背景主色，用淡色主体、青绿或金色小面积边饰形成对比，避免将所有服饰颜色都提高到同样饱和度。
3. **细线要顺着结构。** 毛发、织物和动物毛皮分别遵循生长或褶皱方向；不必让皮肤也密铺线条，以免损失面部与手势可读性。
4. **寓意来自可见关系。** 让人物视线、动作和对象相互呼应；少加道具，保护手势的视觉中心。
5. **书籍用途先看版面。** 无字版本可用于神话、寓言或人物主题插画；用作封面时按实际尺寸另留标题区，正文插图则检查缩小后的细线密度。这些用途尚未制作验证。
