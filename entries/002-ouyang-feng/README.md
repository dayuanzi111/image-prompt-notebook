## 提示词拆解

- 动作参与构图：前伸掌势形成近大远小，衣袍弧线围绕人物，拐杖提供斜向支撑。
- 身份锚点：高鼻深目、棕黄须发、白衣与拐杖。题签进一步点明人物及招式。
- 色彩：本次改写选择竹绿、深墨绿、墨黑、象牙白与赭黄，朱砂用于边栏印章。
- 材质：分别规定皮肤、衣袍、须发和竹干的线条，避免一种噪声覆盖所有表面。
- 空间：人物占据大部分画面，竹林以少量方向性线条衬托动作。

## 实验观察

| 观察项 | 一次生成的结果 |
| --- | --- |
| 人物与画面重心 | 人物面积大，近景手掌和衣袍形成明显视觉重量 |
| 身份特征 | 白衣、棕黄须发、深目和拐杖出现；需结合题签辨认人物 |
| 招式表现 | 前推掌势强烈，但低伏蓄势不够明确，不能仅凭动作认定为蛤蟆功 |
| 构图 | 近景掌势、衣袍曲线、斜向拐杖相互呼应 |
| 中文文字 | 主题签目视为“欧阳锋蛤蟆功”，小题识为“金庸江湖人物志”；印章内容未核验 |

| 材质 | 衣褶和须发线条有区分，但纸面与衣服的斑驳纹理偏多，较原要求更显做旧 |

以上仅为一次输出的观察，尚未验证稳定性。
