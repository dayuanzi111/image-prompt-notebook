## 提示词拆解

| 层次 | 关键描述 | 对画面的作用 |
| --- | --- | --- |
| 情感 | 仰望、轻抬下巴、露齿笑、自然抬起的面颊 | 把温柔落实为眼神与表情，而非只写“浪漫” |
| 空间 | 女子左下、男子右上且靠前、肩背遮挡 | 建立对角关系、距离与层次 |
| 光色 | 偏暗曝光、柔亮面颊与肩部、冷灰绿背景 | 保留阴影，以小范围亮面突出情感中心 |
| 景深 | 女子眼睛与笑容清楚，其余逐层柔化 | 控制注意力，而非把所有细节都变锐利 |
| 细节 | 散发、金耳饰、银十字架、米白衣褶 | 提供自然生活感，优先级低于眼神和构图 |

## 模型适配与补充观点

整理者提出的使用方向是：**Seedream 先强调美学，GPT Image 2.5 明确细节，再按自己的目标补充提示词。** 这是一种值得测试的工作方式。技术事实、经验和本词条的实测记录应分开阅读，详见[模型与提示词学习笔记](../../notes/model-prompting.md)。此观点由本项目整理者提供，不归为 lyshen 的主张。

补充建议：细节应有优先级。本词条首先保证“仰望眼神与自然笑容”，其次是“对角遮挡构图”和“低饱和柔光”，最后才是耳饰、发色与衣料。详细描述的价值在于减少歧义，不在于增加字数。

**关系与约束优先草案（可用于 GPT Image 2.5 实验）**

```text
生成3:4竖幅自然双人近景照片，两人均为年轻成年人。
最高优先级：女子仰望男子，眼睛与自然露齿笑清楚，嘴角和面颊自然抬起。
构图：女子左下，男子右上且靠前；男子肩背遮住女子部分身体，但不挡住她的眼睛和笑容。男子黑发接近上边缘，侧脸朝左、眼睑低垂、嘴角微扬。
色彩与光线：冷灰绿环境与淡粉米色肤面，低饱和低反差，整体偏暗但保留肤色与阴影细节；女子面颊和肩部柔亮，男子脸更暗。
焦点：女子双眼和笑容最清楚；男子略柔，衣料与灰绿窗框背景更柔，右下有浅蓝灰斜向虚焦前景。不要把柔化处理成全脸模糊。
细节：女子栗酒红松散挽发、面颊细发、金色圆耳饰，底部米白露肩衣褶；男子灰棕外衣、少量白色内搭、银色十字架耳饰。
肤质自然细腻，无额外人物、文字或水印。细节发生取舍时优先保证眼神、笑容和人物位置。
```
