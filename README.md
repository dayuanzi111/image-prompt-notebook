## 如何使用

1. 从效果图与分类选择词条。
2. 阅读来源、测试条件及局限，再复制提示词。
3. 替换模板中的主题变量，保存自己的结果与修改记录。

生成结果会受模型、版本与上下文影响。本词典记录观察，不保证同一提示词每次得到相同效果。
